## Ghi chú phương pháp
- Excel: số dòng/cột lấy từ worksheet dimensions; không quét toàn bộ dữ liệu để đếm bản ghi nhằm tránh chi phí lớn. Header ứng viên lấy từ dòng không rỗng đầu tiên trong 8 dòng đầu.
- CSV: đếm dòng bằng đọc theo chunks; lấy header và tối đa 5 dòng mẫu.
- SQLite: liệt kê bảng, schema, COUNT(*) và tối đa 5 dòng mẫu.
- Các sheet Excel có tiêu đề nhiều dòng, ô gộp, ghi chú hoặc nhiều bảng cần kiểm tra thủ công ở bước phân loại.
- README chưa được phân tích ngữ nghĩa trong vòng inventory này.
